This is a series of notes that cover my exploration of coding agents. Coding agents such as Claude Code, Amp, and OpenCode have become quite popular. I have used all of them to create POCs but the noise at the end of 2025 around them by experts and influencers was hard to ignore.

I chose OpenCode for the simple reason that I had mentioned in my [Learnings in 2025](/blog/2025/ai-takeaways-2025/). Open source ecosystem have been a big factor in someone like me learning new languages and new frameworks. The current wave of paid IDEs or Coding Agents with expensive subscriptions is something that will take time getting used to. However, a lot of folks are still releasing high quality tools and models in open source and I would like to bet on the future not changing dramatically in that aspect. Therefore, [OpenCode](https://opencode.ai/)!!

OpenCode is a coding agent harness that provides similar capabilites such as Anthropic's ClaudeCode and OpenAI's Codex. The interesting bit is that it provides access to a few open source models out-of-the-box and you can access pretty much all the models using the OpenCode Zen subscription. I will keep adding new links that talk about specific aspects of my exploration.
